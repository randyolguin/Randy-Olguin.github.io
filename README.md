# Randy Olguin — Engineering Portfolio

A static, responsive portfolio for GitHub Pages. No build tools or dependencies are required.

## Publish with GitHub Pages

1. Upload every file and folder to the root of your GitHub repository.
2. In the repository, open **Settings → Pages**.
3. Under **Build and deployment**, select **Deploy from a branch**.
4. Choose the branch containing the files, select `/ (root)`, and save.

## Update the portfolio

- Edit résumé-backed content and contact information in `index.html`.
- Edit, add, or reorder project cards in `projects.js`.
- Follow `PROJECT-GUIDE.md` to add a project and images.
- Adjust colors and layout in `styles.css`.

The program cards use original SVG illustrations. Public program summaries link to the official L3Harris pages, and a disclosure note separates public mission context from personal work details.
